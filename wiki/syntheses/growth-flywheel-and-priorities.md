# The Growth Flywheel & Near-Term Priorities

**Capstone synthesis (2026-05-24)** tying together everything learned in the first interview.

## The two edges (John's moat — almost no competitor has both)
1. **Deal-Advocate** — gets buyers the builder's price/concessions/buydowns
   ([[wiki/concepts/builder-deal-advocate]]).
2. **Chinese-Language** — serves Chinese-speaking buyers in-language
   ([[wiki/concepts/chinese-language-edge]]).
> Positioning: *"I get you the best deal — and I'll do it in your language."*

## The flywheel
```
   ┌─► 1. BUYER FLOW  (content: deal-advocate proof + Chinese pillar; database reactivation)
   │            │
   │            ▼
   │   2. GIVE FIRST  (send buyers to top agents = reciprocity; serve builder buyers brilliantly)
   │            │
   │            ▼
   │   3. WIN PARTNERS  (top agent + harvested development agents → ongoing referral roster)
   │            │
   │            ▼
   │   4. MORE BUYERS  (partners + builder send deals)
   │            │
   │            ▼
   │   5. MORE CLOSINGS → reviews + referrals + content proof
   └────────────┘   (loops back into buyer flow)
```
Both edges accelerate **every** step. The **finite builder account** is the time-boxed
accelerant that seeds the partner roster (steps 2–3) before it sells out (~12–18 mo).

## The core problem statement
Bottleneck = **leads**. Best clients = **referrals**. Biggest gap = **not enough realtor
partners**. The flywheel solves all three at once: buyer flow → fuels give-first → wins
partners → more referred buyers.

## Near-term priorities (ranked by ROI)
1. **Protect + maximize the builder account NOW** (current revenue, time-boxed).
   Run [[wiki/builder_systems/preferred-lender-conversion-system]] — win pre-approval share
   + convert pre-approval→funded — using both edges (esp. Chinese at
   [[wiki/entities/cordova-development]]).
2. **Give-first on the top agent** ([[wiki/entities/top-realtor-champion]]) — send buyers,
   be flawless on shared deals, serve buyers he can't. Highest-leverage single relationship.
3. **Capture + convert development agents** —
   [[wiki/realtor_systems/realtor-partner-acquisition-playbook]] +
   [[wiki/realtor_systems/realtor-contact-to-partner-conversion]]. Builds the durable roster.
4. **Reactivate the database** —
   [[wiki/strategies/database-reactivation-campaign]]. Fast owned leads (also = gives).
5. **Launch content** — deal-advocate proof + a Chinese pillar
   ([[CONTENT_STRATEGY.md]]). Durable, compounding buyer flow.
6. **Systematize referral + review asks** —
   [[wiki/sales_systems/referral-ask-system]] + [[wiki/sales_systems/review-generation-system]].

## Durable-future moves (beat the finite clock)
- Extend onto the builder's **next projects**; **replicate** the deal-advocate +
  self-advocacy move to win **new builders** ([[BUILDER_STRATEGY.md]]).
