# Content Engine (Persuasion-First Video System)

**Objective (lever):** Leads + Authority. A repeatable system that produces persuasion-first
video without burning John out — the durable buyer-flow source that also fuels give-first.

## Why John stopped (the real problem to fix)
He produced 2–3 videos/week for 1+ year, then stopped for months. The lapse ≈ **production
friction** (editing, thumbnails, captions = doing it all himself). **The fix is delegation +
tooling, not more willpower.** John's only non-delegable jobs are **ideas** and **being
on camera**. Everything else gets a tool or a person.

## The role split (protect John's time)
| Step | Owner |
|---|---|
| Ideas / belief targets | **John** (+ this vault's idea bank) |
| Hooks + scripts | **Claude/vault** drafts → John tweaks ([[wiki/content_systems/script-template]]) |
| On camera | **John** (only this is truly his) |
| Editing | Editor/VA or AI tool (CapCut/Descript/Opus Clip — `TODO: confirm`) |
| Thumbnails | VA/Canva templates ([[wiki/content_systems/thumbnail-and-caption-system]]) |
| Captions | Claude drafts → light human polish |
| Scheduling / posting | VA or scheduler (`TODO: confirm tool`) |
| Repurposing (long→shorts) | AI tool (Opus/Descript) |

## The pipeline
```
Idea bank → pick belief target → Hook → Script (template) → BATCH RECORD
   → Edit → Thumbnail → Caption → Post → Repurpose → Mine comments/DMs
   → new objections back into /raw/objections → new ideas
```

## Batch to beat friction (the restart plan)
1. **One idea session:** fill an idea bank of 10–15 belief-target hooks (use
   [[wiki/content_systems/viral-hooks]]).
2. **One script session:** Claude drafts 6–9 scripts → John edits to his voice.
3. **One record session:** batch-film 6–9 videos (2–3 weeks of content) in one sitting.
4. **Hand off:** editor/VA does edit + thumbnail + caption from the brief.
5. **Schedule + post.** Restart at a **sustainable 2–3/week** (his proven cadence).

## Two pillars (run both)
- **English** — deal-advocate proof + belief-shifting buyer education.
- **Chinese** — same frameworks, in Chinese ([[wiki/concepts/chinese-language-edge]]).
  Near-zero competition = fastest authority.
