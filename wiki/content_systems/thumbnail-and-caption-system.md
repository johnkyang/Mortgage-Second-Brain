# Thumbnail, Caption & Edit Brief System

The production pieces John asked help with. These are **delegation specs** — formulas an
editor/VA (or AI tool) follows so John never touches post-production again.

## Thumbnail formula (for YouTube / long-form)
- **John's face + ONE clear emotion** (shock, curiosity, confidence).
- **3–4 word curiosity/benefit text** — big, bold, readable on mobile. (e.g. "$23K OFF?",
  "NO 20% DOWN", "THE BANK'S LIE").
- **High contrast**, minimal clutter, one focal point.
- Consistent brand look (font/color) so feed is recognizable.
- A/B two thumbnails when possible.
- Tool: Canva template set (`TODO: build 3–5 reusable templates`).

## Caption formula (per platform)
```
Line 1: HOOK (mirror/extend the video hook — stop the scroll)
Body:   the story/value in 2–4 short lines (persuasion, not a transcript)
CTA:    one clear ask ("DM 'PLAN'…", "save this", "who needs to see this?")
Tags:   5–10 relevant + local (#santaclarita #firsttimehomebuyer #losangeles …)
```
- Match platform voice (IG/TikTok punchy; YouTube a bit longer; LinkedIn pro).
- Chinese pillar: caption in Chinese ([[wiki/concepts/chinese-language-edge]]).
- Claude drafts captions from the script → light human polish.

## Edit brief (hand to editor/VA per video)
- Hook on screen in first 1s; cut all dead air; fast pace.
- Captions/subtitles burned in (most watch muted).
- B-roll / text callouts on key points; highlight any real numbers.
- Brand intro/outro, lower-thirds, CTA end card.
- Deliverables: 1 long-form + N vertical shorts (repurpose).
- Tools: CapCut / Descript / Opus Clip for auto-shorts (`TODO: confirm`).

## Delegation workflow (so John stays out of post)
1. John batch-records (with hook stated on camera).
2. Raw files → editor/VA via shared drive + the edit brief.
3. Editor returns long-form + shorts + thumbnail.
4. Claude drafts captions; VA schedules.
→ Track each video through these stages (ClickUp board — see [[wiki/content_systems/content-engine]]).
