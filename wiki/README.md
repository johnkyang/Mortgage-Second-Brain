# /wiki — Derived Knowledge Assets (LIVING)

> Structured, reusable business intelligence extracted from `/raw`. These pages are
> meant to be improved continuously. Every page uses the frontmatter standard in
> [[CLAUDE.md]] §4 and links back to its sources. See templates in `/templates`.

## The knowledge graph (4 node types)
**Sources** feed **Concepts**. **Concepts** + **Entities** power **Strategies/Systems**.

## What goes in each subfolder

| Folder | Holds | Node type |
|---|---|---|
| `sources/` | One page per source (transcript, podcast, mentor, call) | Source |
| `entities/` | People, companies, programs, projects, neighborhoods, competitors | Entity |
| `concepts/` | Frameworks, objections, emotional patterns, definitions | Concept |
| `strategies/` | Cross-cutting strategic plays | Strategy |
| `campaigns/` | Specific marketing/outreach campaigns | Strategy |
| `playbooks/` | Step-by-step repeatable processes | Strategy |
| `scripts/` | Sales/content/outreach scripts | Asset |
| `offers/` | Offers, lead magnets, value props | Asset |
| `automations/` | Automation specs + how they work | Strategy |
| `syntheses/` | Cross-source insights, "big picture" connections | Concept |
| `content_systems/` | Hooks, angles, storytelling, repurposing systems | Strategy |
| `sales_systems/` | Objection banks, discovery, follow-up, conversion | Strategy |
| `builder_systems/` | Builder conversion + outreach systems | Strategy |
| `realtor_systems/` | Realtor referral + co-marketing systems | Strategy |
| `reverse_mortgage_systems/` | Reverse positioning, objections, scripts | Strategy |
| `dpa_systems/` | DPA matrices, FAQs, eligibility, angles | Strategy |

## Page lifecycle
`status: seed` → `developing` → `mature`. Promote as evidence accumulates.
Always: cite sources, link related pages, keep `updated:` current.
