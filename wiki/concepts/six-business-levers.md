# The 6 Business Levers

**One-line definition:** The six outcomes every output in this system must serve —
the universal prioritization filter.

**Why it matters:** Keeps the business (and this AI) focused on revenue-generating work
instead of clever-but-useless novelty.

## The levers
1. **Revenue** — does it make/protect money?
2. **Leads** — does it create qualified prospects?
3. **Appointments** — does it book conversations?
4. **Trust** — does it deepen credibility/relationships?
5. **Efficiency** — does it save time / remove friction?
6. **Authority** — does it build long-term brand dominance?

## How to use it
Before building anything, ask: *"Which lever(s) does this move, and how much?"*
If the honest answer is "none," deprioritize it.

Score initiatives `Impact (on levers) ÷ Effort` to rank the backlog.
